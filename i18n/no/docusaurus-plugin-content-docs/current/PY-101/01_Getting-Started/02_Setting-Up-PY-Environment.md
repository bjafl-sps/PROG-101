> Oppsett av Python-miljø med Visual Studio Code

## 1. Installer Python
#### *Alternativ 1: Installer fra Microsoft Store*
- Hvis du kjører Windows, er det kanskje enklest å installere Python gjennom Microsoft Store. 
- Finn den nyeste versjonen av Python
  - ENTEN åpne Microsoft Store-appen på din PC og søk etter *python*
  - ELLER følg [denne lenken](https://apps.microsoft.com/search?query=python) for å søke etter *python* på https://apps.microsoft.com
- Klikk installer

#### *Alternativ 2: Last ned fra python.org*
- Last ned den nyeste versjonen av Python fra den [offisielle nettsiden](https://www.python.org/downloads/) og kjør installasjonsprogrammet.
- Hvis du ser en avkryssingsboks som sier "Add Python x.x to PATH", kryss av for at Python skal kunne kjøre fra kommandolinjen.

## 2. Visual Studio Code
### 2.1 Installer VS Code
#### *Alternativ 1: Installer fra Microsoft Store*
- Søk etter *vscode* i MS Store-appen, eller følg [denne lenken](https://apps.microsoft.com/search?query=vscode).
- Finn og installer *Visual studio code*
#### *Alternativ 2: Last ned fra visualstudio.com*
- Last ned og installer Visual Studio Code fra den [offisielle nettsiden](https://code.visualstudio.com/).

### 2.2 Installer Python-utvidelse for VS Code
- Åpne Visual Studio Code.
- Gå til Extensions-visningen ved å klikke på firkant-ikonet på venstre sidemeny eller ved å trykke `Ctrl+Shift+X`.
- Søk etter "Python" i Extensions Marketplace.
- installer Python-utvidelsen levert av Microsoft.

##  3. Git
### 3.1 Installer Git:
- Last ned og installer Git fra den [offisielle nettsiden](https://git-scm.com/downloads).

### 3.2 Koble GitHub-konto til VS Code:
- I VS Code, åpne Source Control-visningen ved å klikke på det tredje ikonet i sidemenyen eller ved å trykke `Ctrl+Shift+G`.
- Klikk på "Sign in to GitHub"-knappen og følg instruksjonene for å logge inn og autentisere din GitHub-konto.
